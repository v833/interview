# 按住说话

按住按钮不放开始录音，松开就停、自动识别、直接提问。
走**麦克风**，和微信一样。不想打字时用。

也可以按全局快捷键 <kbd>Space</kbd>（按住），效果一样。

## 几个细节

**录的是麦克风，不是 loopback。**
所以**面试官的声音不会被录进来**。两条链路用的是不同设备，可以同时开着互不干扰——
一边监听面试官，一边按住说话问你自己的问题。

**识别结果会留在输入框里。**
所以你能看见它到底听成了什么。

**按太短（< 0.3 秒）会提示「按住别放，说完再松开」**，不会白跑一次识别。

**识别中再按会提示「稍等一下」**，不会叠起来起第二个线程。

**单次最长 30 秒自动停。**
（讯飞单次会话上限 60 秒，这里留了充足余量。）

## 麦克风选不对怎么办

「设置」→ 语音识别 → **麦克风（按住说话）**，默认「系统默认麦克风」通常就够。

拿不准就跑：

```powershell
.\.venv\Scripts\python.exe run.py --check
```

它会打印实际会用的那个设备名。

::: warning 别和「采集设备」搞混
- **采集设备** = 系统输出 = 面试官的声音
- **麦克风（按住说话）** = 你自己的声音

`audio.device` 和 `audio.mic_device` 是两个独立的配置项，留空都是自动。
:::

## 想先看一眼再决定发不发？

那就用输入框打字。

「按住说话」是**设计成不二次确认**的——少点一下才是它的价值所在。
如果你需要审核识别结果，输入框是更合适的入口。
