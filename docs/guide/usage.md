# 界面与操作

![界面预览](/preview.png)

## 快捷键

| 快捷键 | 作用 |
|---|---|
| <kbd>Space</kbd>（按住） | 开始录制麦克风，松开后自动识别并提问 |
| <kbd>B</kbd> | 开始 / 停止监听 |
| <kbd>N</kbd> | 把最近几句字幕拼起来提问（同「问最近」） |
| <kbd>M</kbd> | 清空字幕、问题和回答 |
| <kbd>J</kbd> | 框选屏幕区域并自动截图提问 |
| <kbd>Ctrl</kbd>+<kbd>Alt</kbd>+<kbd>H</kbd> | 显示 / 隐藏窗口 |
| <kbd>Esc</kbd> | 退出提问输入框，恢复全局快捷键；截图模式下取消框选 |

**六个全局快捷键都可以在「设置 → 界面」中修改，留空则禁用。**

::: tip 输入框聚焦时单键会失效
单键（`B` / `N` / `M` / `J` / `Space`）在输入框获得焦点时会被让给打字，
按 <kbd>Esc</kbd> 退出输入框即可恢复。
:::

## 实时字幕

字幕是**一句一行**的，每行末尾都有「**提问此句**」按钮。

面试官说了句关键的话、但规则没识别成问题，直接点那一句就行，
不用把整段都发过去。

## 窗口操作

- **拖动标题栏**可以移动窗口
- **右下角**可以拉伸大小
- 位置和尺寸会**自动记住**，下次启动回到原处
- 显示器拔掉或分辨率变了会自动放弃记录，不会跑到看不见的地方

## 防截屏

窗口用 `SetWindowDisplayAffinity(WDA_EXCLUDEFROMCAPTURE)` 排除在屏幕捕获之外。
标题栏会提示「**防截屏已开启**」。

::: danger 面试前务必验证一次
开着悬浮窗，用腾讯会议「共享屏幕」看一眼，确认**对方视角里看不到它**。
不要靠「应该没问题」。
:::

限制见[已知限制](../reference/limits.md)。

## 输入框

在输入框里输入任意问题，**回车**或点「提问」直接问大模型。
不依赖麦克风，也不依赖前面有没有识别到字幕。

输入框空着按回车**不会白发请求**，状态栏会提示「先输入要问的内容」——
不让点击变成「没反应」。

## 状态栏提示

界面上所有反馈都走状态栏，常见的几条：

| 提示 | 含义 |
|---|---|
| 正在生成… | 请求已发出，等首字 |
| 先输入要问的内容 | 输入框是空的 |
| 按住别放，说完再松开 | 按住时间短于 0.3 秒 |
| 稍等一下 | 上一次识别还没结束 |
| 还没听到声音，检查采集设备 | 采集 12 秒无输入 |
