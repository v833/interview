# 它是什么

**侧耳（Sotto）是一个面试副驾。** 它实时抓取腾讯会议里面试官的声音，在本地转成文字，
判断哪句是提问，交给大模型流式生成回答，最后在一个置顶悬浮窗里吐出来——短到可以直接照着念。

![界面预览](/preview.png)

全程不需要虚拟声卡，不需要开立体声混音，共享屏幕时对方也看不到这个窗口。

## 一条链路走下来

```
扬声器输出（面试官的声音）
        │  WASAPI loopback 采集
        ▼
   能量型 VAD 断句 ── 静音持续 0.6s 判定一句说完
        ▼
   语音识别 ── 讯飞流式听写（云端） 或 faster-whisper（本地离线）
        ▼
   提问判定 ── 疑问词 / 祈使句 / 问号 / 语气词 规则打分
        ▼
   大模型作答 ── DeepSeek 流式输出，上下文里带上你的简历和 JD
        ▼
   置顶悬浮窗 ── 边生成边显示，逐字出现
```

## 三个设计上的取舍

**采集、识别、作答分成三条常驻线程，用队列解耦。**
采集线程永远不阻塞——哪怕识别慢，音频也不会丢在采集端。识别和作答分开之后，
慢的模型只影响回答出现的时间，不影响你能不能继续听到面试官说话。

**作答链路不依赖声卡。**
`Answerer` 和作答线程独立于采集链路存在。所以「停止监听」之后，打字提问、
按住说话、问最近**照样能用**——你可以停掉监听再慢慢追问刚才那一句。

**新问题来了，旧回答立刻作废。**
面试官不会等你把上一题念完。检测到新的提问时，正在流式生成的旧回答会被立刻取消，
不会出现两个答案交错刷屏。

## 识别引擎：云端还是本地

默认 `auto`：**填了讯飞凭证就用讯飞，没填就自动用本地 whisper。**

| | 讯飞语音听写 | 本地 faster-whisper |
|---|---|---|
| 是否联网 | 需要 | 完全离线 |
| 模型下载 | 不需要 | `small` 约 484MB |
| 延迟 | 端到端主要就是 0.6s 断句等待 | 无独显 `small` 约 1.5~3s |
| 隐私 | **面试语音会上传到讯飞服务器** | 语音不出本机 |
| 费用 | 免费额度够个人用，用尽需充值 | 免费 |

两种可以都配好，在设置里改「识别引擎」下拉随时切换。断网或凭证失效时也能切回本地。
