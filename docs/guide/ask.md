# 五种提问方式

提问有五个入口，按场景选。**五者都不依赖「开始监听」**——没在采集时也能用
（比如手动把一句话敲进去，或者停掉监听后想再问问刚才那句）。

## 对比

| 方式 | 入口 | 适合 |
|---|---|---|
| 自动判定 | 「开始监听」后自动 | 正常面试流程，不用管 |
| **按住说话** | 麦克风按钮 / <kbd>Space</kbd> | 手不离键盘、不方便打字 |
| **打字提问** | 输入框 + 回车 | 追问细节、自己练习。最灵活 |
| **提问此句** | 字幕行右侧按钮 | 面试官刚说的某一句就是问题 |
| **截图提问** | 底部按钮 / <kbd>J</kbd> | 屏幕上的代码、题目、图表 |
| **问最近** | 底部按钮 / <kbd>N</kbd> | 规则漏判了，把最近几句拼起来 |

---

## 1. 自动判定

开始监听后，每一句识别出来的话都会过一遍规则打分：疑问词、祈使句、问号、语气词，
分数超过 `question.threshold`（默认 3.0）就自动作答。

漏判和误判都靠阈值调，见[调参速查](../reference/tuning.md)。

## 2. 按住说话

手不离键盘、不方便打字时用。按住说、松开就发，不用再点一次。
详细说明见[按住说话](./voice-input.md)。

## 3. 打字提问

输入框里输入任意问题，**回车**或点「提问」直接问大模型。
不依赖麦克风，也不依赖前面有没有识别到字幕。

想追问一个细节、或者自己练习时随便问点什么，用这个最灵活。

## 4. 提问此句

每句实时字幕右侧都有这个按钮，把**这一句**单独发给大模型。

面试官说了句关键的话、规则没识别成问题，点那一句就行，
不用把整段都发过去。

## 5. 截图提问

框选当前屏幕区域，松开后由**多模态模型**直接读取并回答。<kbd>Esc</kbd> 取消。

::: warning 需要模型支持图片输入
截图提问要求当前模型支持 OpenAI 兼容的图片输入。

- ✅ `deepseek-flash` — 已验证可用
- ❌ `deepseek-chat` 等纯文本模型 — 接口会直接返回不支持图片的错误
:::

## 6. 问最近

规则漏判时，把最近几段实时字幕拼起来直接问。

- 默认取 **3 条**
- 可在「设置 → 语音识别」中选择 **1–8 条**（对应 `question.recent_count`）
